NAME

myip.addr.tools - get your public IP address

SYNOPSIS

$ curl https://myip.example.com 2001:db8::c0:ffee

$ curl https://myipv4.example.com 192.0.2.1

$ curl https://myipv6.example.com 2001:db8::c0:ffee

$ curl https://myip.example.com/json {"ip":"2001:db8::c0:ffee"}

DESCRIPTION

Returns your public IP address. That's it.

FORMATS

By default, your IP is returned with a trailing newline character. Change this by specifying a format:

/plain no trailing newline
/json a JSON object
/json?key=foo a JSON object with custom key
/pfsense a pfSense IP Check Service

STUN

The original service operates a public STUN server on port 3478. A deployment of this fork must configure its own STUN service if that optional feature is required.
