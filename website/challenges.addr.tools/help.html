ACME challenge helper

DNS-01 certificate validation

This documentation describes the modified fork. Reserved example.com and *.example names below are placeholders; configure your own service domains. The original public addr.tools services are operated independently.

HOW IT WORKS

This service publishes temporary TXT records for ACME DNS-01 challenges. Your domain’s _acme-challenge CNAME points to a name derived from your secret. A certificate authority such as Let’s Encrypt follows that delegation.

CREATE A SECRET

Generate 32 random bytes in canonical unpadded base64url format (43 characters). The API requires this exact token format and rejects query-string credentials. Generate the token cryptographically: a format check cannot prove randomness. Create private files without printing the secret:

umask 077 openssl rand -base64 32 | tr '+/' '-_' | tr -d '=\n' > secret.token { printf 'Authorization: Bearer '; cat secret.token; printf '\n'; } > auth.header sha224=$(openssl dgst -sha224 -r secret.token | cut -d ' ' -f 1)

The public SHA-224 name is an offline verifier for password guesses. Keep the random token private. Rotating it changes the target name, so update the CNAME delegation too.

ADD A CHALLENGE

Send POST or PUT with Authorization: Bearer SECRET and a txt field in a URL-encoded form or JSON body. Success returns HTTP 201 and OK.

curl --fail-with-body --header @auth.header --data-urlencode "txt=$CERTBOT_VALIDATION" https://challenges.example.com/

A GET with only the bearer header returns the derived domain without changing state. GET requests containing txt and credentials in URLs are rejected.

At most 8 distinct challenges can be active for one name. Adding the same challenge refreshes its lifetime instead of creating a duplicate. A DELETE request with the bearer header and the txt body field removes that one challenge and returns HTTP 204. Challenges otherwise expire after 120 seconds.

DELEGATION AND AUTOMATION

printf "%s.challenges.example.com\n" "$sha224"

Use the printed name as the CNAME target of _acme-challenge.example.com. A fixed Certbot hook script should read the protected credential file and submit the validation string as encoded data. Do not insert secrets into a shell command that will be parsed again.

See the maintained certificate helper scripts in this fork. Configure them with your own endpoint and protected secret file before use. The helper does not replace the need to control the domain’s DNS delegation.

DATA HANDLING

Challenge TXT records are public while active. The service processes update source addresses and can log requests. Operators must document retention and access. A bearer credential grants control over this challenge name and must not appear in logs.
